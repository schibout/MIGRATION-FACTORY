Recharger les tables

BoutonExtraction SAPPérimètreModule ETL fournisseurs
RecalculerNonRepris tel quelOui
Synchroniser SAPOuiRecalculé, même date d'arrêtéOui
  • Utilisez Recalculer après avoir calculé le périmètre ou importé le fichier validé dans Finance > Fournisseurs.
  • La liste reste en attente pendant le rechargement. Elle se met à jour à la fin.
  • En cas d'échec du module ETL, les tables restent dans leur état précédent et l'erreur s'affiche.
  • Ces boutons remplacent les données chargées : les exports IFS suivants reprendront le nouveau contenu.

Une pastille orange signale un contrôle avec au moins un fournisseur concerné. Certains cas peuvent être normaux, par exemple un fournisseur sans méthode de communication dans SAP.

4
Utilisation

Recherche et export

  • La recherche porte sur le N° IFS, le N° SAP et le nom, ainsi que sur le code article dans l'onglet Articles. Validez avec Entrée.
  • Exporter Excel produit une feuille par table de l'onglet affiché, avec la recherche appliquée et toutes les lignes.
  • Les colonnes gardent leur nom technique IFS. Les colonnes d'audit ne sont pas affichées.
5
À savoir

Limites connues

  • purchase_part_supplier dépend du module ETL Articles : ces boutons ne la rechargent pas.
  • Un fournisseur sans N° IFS n'est pas chargé. Importez d'abord le fichier validé dans Finance > Fournisseurs.
  • Un périmètre vide arrête le rechargement avec une erreur.
  • Une seule synchronisation à la fois depuis cet écran. Évitez de lancer en même temps le module depuis l'écran ETL.
